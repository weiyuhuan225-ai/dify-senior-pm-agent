## 4 User stories

### User stories

- **US-1** Goals: G-1; Persona: P-1; Description: As an organizer, I want to record a book being lent out or returned so that I can track its current lending status.

## 5 Functional requirements

### Functional requirements

- **FR-1** Acceptance criteria: After a successful save, the status in the list matches the record; Stories: US-1; Description: Create a lending record and update it as returned

## 6 User experience

### Entry points

The lending list in the web interface.

### Core flow

Create a record from the list and enter the book title, borrower alias, and date. Return to the list after saving, and update the same record when the book is returned.

### Edge cases

Duplicate submissions show a message that the record already exists. If saving fails, preserve the entered information and allow a retry.

### Interface priorities

Prioritize records of books currently on loan and a clear save status.
